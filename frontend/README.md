# Cardio Atlas AI — Frontend

Run from project root: `npm install` then `python run.py`.

For frontend-only mode: `npm install` and `npm run dev` in this directory. Backend-dependent scores and explainability require FastAPI.

Modernized React / Vite workstation with landing, analytics dashboard, 3D X-ray heart explorer, assessment, simulation, explainability, history, model intelligence and downloadable UCI dataset library.

The project contains research data only and is not a medical device. See `../README.md` for full attribution and instructions.
